# AI Character Chat Mobile (Expo)

## Stack
- React Native + Expo
- TypeScript

## Run
```bash
cd apps/client/mobile
npm install
npm run start
```

## Environment
```bash
# apps/client/mobile/.env
EXPO_PUBLIC_API_BASE_URL=http://127.0.0.1:8000
```

If you test on a real phone, replace 127.0.0.1 with your PC local IP.
Example: EXPO_PUBLIC_API_BASE_URL=http://192.168.0.10:8000
